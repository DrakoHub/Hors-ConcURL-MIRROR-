#Hors-ConcURL
##(EN)
_Hors-ConcURL_ is a small utility written in zig, made to transfer data between computers in a parallel, or sequential, manner. Focused on high performance and safety.
_Similar tools:_
- curl
- wget
- aria2
##How to Build:
Requirements:
- zig 0.16 or higher
```bash
git clone https://codeberg.org/RTarsiHub/Hors-ConcURL
cd Hors-ConcURL
zig build
```
